## 🚀 这是什么？

**把“空域”变成可量化、可交易的数字资产——纯本地、零上传、秒级响应。**

AirMind 不是一块冰冷的监控大屏，而是一套**会博弈、懂仿生、能应急**的低空经济决策操作系统。它融合了凯利公式的博弈均衡、人体前庭平衡的仿生控制、以及串级 PID 的工业级闭环，让城市物流、应急救援和载人交通（UAM）的调度像呼吸一样自然。

- **🎯 博弈定价**：用凯利公式动态计算最优出价，避免亏本抢单或错失良机。
- **🧬 仿生控制**：将人体“皮肤风感 → 前庭平衡 → 视觉修正”映射为无人机“空速管 → IMU → SLAM”，侧风突袭也能稳如磐石。
- **🚨 秒级应急**：输入灾情参数，策略引擎毫秒级匹配最优救援方案（疏散/物资/通信），并一键生成 PDF 报告。
- **🔒 绝对隐私**：纯本地运行（localStorage），数据主权归你，零上传，敏感运营数据永不离机。

## ⚡️ 5 分钟快速上手（零安装）

> **想先看看效果？** → [在线 Demo 入口](#)（占位，部署后替换）

**本地运行（无需 Node.js）：**
```bash
git clone https://github.com/Y-Mine/airmind-os.git
cd airmind-os
# 双击 index.html 直接运行，或用 VS Code Live Server 打开
```

**5 步体验完整闭环：**
1. **配置**（Tab 6）→ 注册 2 家企业，录入 4 款无人机机型。
2. **创建任务**（Tab 3）→ 输入载重/距离，系统自动推荐 Top 3 匹配机型（含电池 SOH 校验）。
3. **博弈竞价**（Tab 2）→ 滑动参数，凯利公式实时计算最优出价比例。
4. **总控监视**（Tab 1）→ 观察“绿/黄/红”稳态色带，追踪四大底座（博弈→定价→物流→算力）的流光动画。
5. **应急演练**（Tab 5）→ 填入“火势等级/被困人数”，看策略引擎秒级亮出最优解并导出 PDF。

<details>
<summary><b>🧮 关键算法模型（点击展开）</b></summary>

**1. 凯利公式（Kelly Criterion）—— 解决“出价多少才不亏”**
> `f* = (b·p - q) / b`  
> 应用场景：空域时隙拍卖中，代入“潜在收益（b）”和“中标概率（p）”，算出最优本金比例，避免因贪婪或保守导致长期增长率归零。

**2. 电池健康度（SOH）—— 杜绝“空中断电”**
> 简化模型：`SOH = 100 - degradation`（基于循环次数 + 温度惩罚）  
> 🟢 ≥80%（长途任务）｜🟡 60%~80%（短途轻载）｜🔴 <60%（强制停飞）

**3. 运力匹配度 —— 选最对的那架飞机**
> `匹配度 = (载重余量×0.4) + (续航余量×0.4) + (电池SOH×0.2)`  
> 对每项任务自动计算所有可用机型，输出 Top 3 推荐。

**4. 综合定价指数 —— 随行就市，动态博弈**
> `最终价 = 基础价 × 时段系数(0.8~1.2) × 气象系数(1.0~1.3) × 拥堵系数(1.0~1.25)`
</details>
